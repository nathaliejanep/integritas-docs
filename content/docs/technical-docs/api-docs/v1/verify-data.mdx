## NFT Proof Trace (Optional Feature)

The **NFT Proof Trace** is an optional feature in the API that allows you to request an NFT trace of the verification process.

When enabled:

- It provides an **immutable, on-chain record** of the validation.
- The verification is **linked to a unique NFT**, ensuring transparency and traceability.

## Request Body (Choose one)

| Request Type               | Content-Type                          | Body Type   | Keys                | Description                                                                                   |
| -------------------------- | ------------------------------------- | ----------- | ------------------- | --------------------------------------------------------------------------------------------- |
| {REQUEST_TYPE_FILE_UPLOAD} | <code>{CONTENT_TYPE_MULTIPART}</code> | `form-data` | `file`              | Validate a source file.                                                                       |
| {REQUEST_TYPE_FILE_UPLOAD} | <code>{CONTENT_TYPE_MULTIPART}</code> | `form-data` | `file`              | Validate a `.tar` file. The `.tar` file should contain the source file and a JSON proof file. |
| {REQUEST_TYPE_FILE_UPLOAD} | <code>{CONTENT_TYPE_MULTIPART}</code> | `form-data` | `file`, `jsonproof` | Validate a source file with a JSON proof file.                                                |

<Callout type='info' title='Note: Uploading Hash to Blockchain'>
When verifying with only a source file (without a proof file), the file's hash must already exist on the blockchain to receive a match result.

To upload a hash to the blockchain, you can send it directly from your own Minima node using this terminal command:

```bash
send address:0x29f774d99ae3e3494ee4a69f3a11a8248362506a9b9bc526f8c98ab6deca68f5 amount:0.000000000000001 state:{"99":"[YOUR_HASH]"}
```

Replace `[YOUR_HASH]` with your actual file hash. This sends the transaction from your own node directly to the blockchain.

</Callout>

```typescript
// Using fetch API
const API_KEY = 'your-api-key';
const REQUEST_ID = 'your-choice';

async function verifyData(
  filePath: string,
  proofPath?: string,
  reportRequired: boolean = true
) {
  const formData = new FormData();

  // For browser: use file inputs
  // const fileInput = document.querySelector('input[name="file"]');
  // formData.append('file', fileInput.files[0]);

  // For Node.js: use fs
  const fs = await import('fs');
  const file = fs.readFileSync(filePath);
  const fileBlob = new Blob([file]);
  formData.append('file', fileBlob, 'yourfile.pdf');

  // Optional: add proof file
  if (proofPath) {
    const proofFile = fs.readFileSync(proofPath);
    const proofBlob = new Blob([proofFile]);
    formData.append('jsonproof', proofBlob, 'yourproof.json');
  }

  const response = await fetch(
    'https://integritas.technology/core/v1/verify/post',
    {
      method: 'POST',
      headers: {
        'x-api-key': API_KEY,
        'x-request-id': REQUEST_ID,
        'x-report-required': reportRequired.toString(),
      },
      body: formData,
    }
  );

  const data = await response.json();
  console.log('Response:', data);
  return data;
}

// Usage
// Verify with source file only
verifyData('./path/to/yourfile.pdf');

// Verify with source file and proof
verifyData('./path/to/yourfile.pdf', './path/to/yourproof.json');
```

  <Tab value='Python'>

```python
import requests

API_KEY = 'your-api-key'
REQUEST_ID = 'your-choice'

def verify_data(file_path, proof_path=None, report_required=True):
    url = 'https://integritas.technology/core/v1/verify/post'

    headers = {
        'x-api-key': API_KEY,
        'x-request-id': REQUEST_ID,
        'x-report-required': str(report_required).lower(),
    }

    files = {}

    with open(file_path, 'rb') as file:
        files['file'] = file

        # Optional: add proof file
        if proof_path:
            with open(proof_path, 'rb') as proof_file:
                files['jsonproof'] = proof_file
                response = requests.post(url, headers=headers, files=files)
        else:
            response = requests.post(url, headers=headers, files=files)

    data = response.json()
    print('Response:', data)
    return data

# Usage
# Verify with source file only
verify_data('./path/to/yourfile.pdf')

# Verify with source file and proof
verify_data('./path/to/yourfile.pdf', './path/to/yourproof.json')
```
