## Base URL

All v2 API requests are made to the following base URL:

```text
https://integritas.minima.global/core/v2
```

### Example

To make a request to the "Verify file" endpoint, you would use:

```text
https://integritas.minima.global/core/v2/verify/file
```

## Endpoints Overview

There are three available v2 endpoints.

1. **[Stamp file](/docs/technical-docs/api-docs/v2/stamp-file)** - Submit a hash (or check if it already exists). Returns verification data when the hash is already on-chain.

2. **[File check](/docs/technical-docs/api-docs/v2/file-check)** - Check whether a hash exists on the blockchain. Returns a simple found/not-found result.

3. **[Verify file](/docs/technical-docs/api-docs/v2/verify-file)** - Verify a file by sending its hash. Returns verification results and optionally a PDF report when `x-report-required` is set.
